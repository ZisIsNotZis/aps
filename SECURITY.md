# Security policy

APS is an experimental local planning tool and is not hardened for direct
internet exposure. Run it behind appropriate network controls and never send
secrets or confidential production data to an unreviewed instance.

Please do not publish a suspected vulnerability in an issue. Report it
privately to the repository maintainers through the contact mechanism on the
GitHub repository, including reproduction steps, affected files, and impact.
Do not include real customer data in the report.
